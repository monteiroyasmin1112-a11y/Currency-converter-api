# Currency Converter API

A simple currency converter built with Python using the Frankfurter API.

## Features

- Convert currencies using exchange rates from an API
- Validate currency codes
- Handle API errors
- Display the converted amount

## Technologies

- Python
- REST API
- Frankfurter API
